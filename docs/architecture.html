关键设计决策 TRADE-OFFS

LLM 不碰事实与算钱

模型只负责选点、排程与文案；坐标、价格、校验、预算由代码负责。

单一事实源

一份 Trip 数据驱动时间轴、地图、预算和 PDF，避免多端状态漂移。

异步 + SSE

长任务进 Worker，事件可回放；断线重连，不阻塞 API 进程。

服务端导出

Playwright 渲染 A4 模板，中文字体、分页、地图截图都可控。

架构一句话： 用模块化单体守住交付速度，用 Agent 提升规划上限，用确定性引擎守住可信度。
